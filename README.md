# CENTER LAB · PTCG 居中度测量

浏览器本地运行的 PTCG 卡牌居中度测量工具，支持原图像素精度、八点边线定位、比例约束内框识别和无标记透视校正导出。

[在线使用](https://bibibivlin.github.io/ptcg-center-lab/) · [MIT License](LICENSE)

## 功能

- **原图精度**：解码后的完整图片是定位、处理与计算空间；仅显示预览允许缩放，定位坐标以双精度浮点数保存。
- **外框八点 + 内框八点**：上、右、下、左每边各两个独立控制点；点位靠近圆角两侧的直边，四角由边线交点计算。
- **自动初步识别**：外框采用连通区域与稳健边缘拟合；内框先按外框校正透视，再用窄/常规/宽边框参考或自定义宽高比例搜索连续水平与竖直边界。位置、连续性、颜色与相对边总边距参与筛选，不强制 50:50 居中。
- **手动定位与精调**：单点、整条边、同一角附近内外框四点联动，坐标输入，0.1 / 1 / 10 px 微调、撤销重做和局部放大。
- **响应式工作台**：手机保持图片与微调控件同屏；左侧上下排列选点和精度，右侧为十字方向键。支持双指缩放、平移和全页面图片拖入。
- **导入导出**：无舍入定位 JSON、原图尺寸标注 PNG、原图像素密度的无标记透视校正 PNG；兼容旧版四角 JSON。
- **本地处理**：无账号、无后端、无第三方脚本或图片上传；仅需静态文件托管。

## 本地运行

需要 Node.js 20 或更高版本，无需安装依赖。

~~~sh
npm start
~~~

打开 http://127.0.0.1:4173 。

生成单文件离线版本：

~~~sh
npm run build
~~~

产物为 outputs/PTCG-Center-Lab.html，可直接使用现代浏览器打开。多文件版本请通过本地服务器或 HTTPS 托管使用，以便加载 Web Worker。

## 操作

1. 上传卡牌照片，或将图片拖入页面任意区域。
2. 核对外框，再展开“坐标与边线工具”，选择内框搜索参考；必要时输入自定义内外框宽高比例，保留外框后重识别内框。
3. 使用四点联动粗调角落，再切回单点精调。控制点应放在圆角两侧的直边上，避开弧线。
4. 查看左右与上下边距比例，导出定位数据或无标记校正图片。

自动识别仅为初步定位。参考比例并非所有卡牌的统一尺寸；候选边界存在歧义或证据不足时会提示核对，推测边线会标注为待校准。

## GitHub Pages

仓库的 .github/workflows/pages.yml 在 main 分支更新后自动执行检查，随后将 dist 发布到 GitHub Pages。Pull request 只运行检查。

首次启用时，将仓库 Settings → Pages → Build and deployment → Source 设置为 **GitHub Actions**。不需要部署密钥或仓库 Secrets。发布流程只上传 dist，使用相对资源路径，兼容 /ptcg-center-lab/ 这样的项目子路径。

## 检查

~~~sh
npm test
~~~

覆盖原图浮点坐标、透视变换、窄边框与强图案干扰、真实偏心、自定义比例、缺失边线提示、6000 × 8000 原图逐像素处理、单点与四点联动、撤销重做、JSON 兼容和无标记导出。交互检查使用 DOM 测试替身，不等同于手机实机视觉验证。

## 精度与限制

- 按 63:88 卡牌长宽比校正透视，边距取校正后水平和垂直中线；px 是以原图外框平均宽度为尺度的校正等效像素。
- 无标记导出直接对原图分块读取并做带 alpha 的双线性透视采样，输出卡牌裁切图；不使用缩小预览，也不绘制定位点、文字或边线。
- 亚像素坐标精度不等于真实测量准确度。卡套、反光、模糊、全图或没有唯一印刷边界的卡牌仍需人工核对；结果不代表评级结论。
- 超大图片可能超出浏览器内存、解码或画布限制；不会为自动识别而静默缩小原图。

## 目录

- dist/：可直接托管的 HTML、CSS、JavaScript 与 Web Workers。
- tests/：几何、识别、原图处理、交互和导出检查。
- tools/：本地服务器、单文件打包器及检查入口。
- .github/workflows/pages.yml：自动检查与 Pages 发布。
