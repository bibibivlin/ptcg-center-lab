# CENTER LAB · PTCG 居中度测量

浏览器本地运行的 PTCG 卡牌居中度测量工具，支持原图像素精度、八点边线定位、比例约束内框识别和无标记透视校正导出。

[在线使用](https://bibibivlin.github.io/ptcg-center-lab/) · [MIT License](LICENSE)

## 功能

- **原图精度**：解码后的完整图片是定位、处理与计算空间；仅显示预览允许缩放，定位坐标以双精度浮点数保存。
- **外框八点 + 内框八点**：上、右、下、左每边各两个独立控制点；点位靠近圆角两侧的直边，四角由边线交点计算。
- **上传后自动识别**：先根据颜色梯度、长直边、背景一致性和卡片形状选择完整外框，再在原图上精修并立即显示。随后按透视校正后的参考比例搜索内框；四边可信度不足或存在歧义时，整体回退为外框内的居中估算框。可靠的实测内框保留真实偏心。
- **自动定位后微调**：自动生成内外框起点，支持单点精调、同一角内外框四点联动、0.1 / 1 / 10 px 步长、撤销重做和局部放大。
- **响应式工作台**：微调区按面板宽度排列调整对象、步长和横排方向按钮；手机通过“工作台／测量结果”页签切换。支持双指缩放、平移和全页面图片拖入。
- **导入导出**：无舍入定位 JSON、原图尺寸标注 PNG、原图像素密度的无标记透视校正 PNG；兼容旧版四角 JSON。
- **本地处理**：无账号、无后端、无第三方脚本或图片上传；仅需静态文件托管。

## 本地运行

需要 Node.js 20 或更高版本，无需安装依赖。

~~~sh
npm start
~~~

打开 http://127.0.0.1:4173 。

生成单文件离线版本：

~~~sh
npm run build
~~~

产物为 outputs/PTCG-Center-Lab.html，可直接使用现代浏览器打开。多文件版本请通过本地服务器或 HTTPS 托管使用，以便加载 Web Worker。

## 操作

1. 上传卡牌照片，或将图片拖入页面任意区域。
2. 等待自动识别：优先定位外框，再识别内框。先核对外框，再核对内框；需要重新计算时点击“重新自动识别”（手机为“自动识别”）。
3. 使用四点联动粗调角落，再切回单点精调。控制点应放在圆角两侧的直边上，避开弧线。
4. 选择调整对象和步长，通过横排方向按钮或键盘方向键微调；使用放大定位、撤销和重做辅助核对。缩放栏按“适应、1:1、−、百分比、＋”排列。“原图／校正预览”切换观察视图。
5. 查看左右与上下边距比例，导出定位 JSON、原图标注 PNG 或无标记校正 PNG；以后可先加载同一原图，再导入 JSON 恢复定位。

自动识别仅为初步定位。内框检测要求四边连续性评分均达到 85，且没有相近候选；否则按内置现代卡牌比例假设完美居中。自动模式的回退参考为内框宽 92%、高 94.3%（按 63 × 88 mm 换算约为每侧 2.5 mm）。这是内置的工程参考，不是所有现代卡牌的统一印刷标准。界面和 JSON 会标记估算来源，初始 50:50 不能当作实测居中度。

## 检查

~~~sh
npm test
~~~

覆盖原图浮点坐标、透视变换、窄边框与强图案干扰、真实偏心、自定义比例、缺失边线提示、6000 × 8000 原图分块采样与 2 亿像素坐标、单点与四点联动、撤销重做、JSON 兼容和无标记导出。交互检查使用 DOM 测试替身，不等同于手机实机视觉验证。

## 实拍照片验证

实拍照片不随仓库分发，`sample/` 已被 Git 忽略。维护者在本地备有与 `tests/sample-frames.json` 对应的 9 张照片时，可运行可选浏览器回归。先启动 `npm start`，再在安装了 Playwright 和 Chromium 的环境运行 `node tests/photos.cjs`；Windows 可设置 `PTCG_BROWSER_CHANNEL=msedge` 使用本机 Edge。Playwright 仅用于此可选检查，常规 `npm test` 无需安装依赖。也可运行 `npm test -- --photos` 将实拍回归接在常规检查之后。

检查包括原始照片上传、EXIF 方向、先返回外框、估算标签与 JSON、近似裁切边缘标注，以及桌面/手机截图。结果写入 `outputs/sample-validation/`。标注容差用于发现误框整幅插画等回归，不代表测量精度。照片不参与发布。

## 精度与限制

- 按 63:88 卡牌长宽比校正透视，边距取校正后水平和垂直中线；px 是以原图外框平均宽度为尺度的校正等效像素。
- 无标记导出直接对原图分块读取并做带 alpha 的双线性透视采样，输出卡牌裁切图；不使用缩小预览，也不绘制定位点、文字或边线。
- 亚像素坐标精度不等于真实测量准确度。卡套、反光、模糊、全图或没有唯一印刷边界的卡牌仍需人工核对；结果不代表评级结论。
- 超大图片可能超出浏览器内存、解码或画布限制；检测在原图上稀疏采样以寻找候选，随后进行原像素边缘精修；候选阶段的采样网格不替代原图，精修和输出保留原像素坐标。Worker 使用最多 64 个 256 × 256 原图块（约 16 MiB 像素缓存），不再分配多份整图数组；原图解码本身仍需浏览器内存。
